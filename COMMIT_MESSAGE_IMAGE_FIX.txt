Fix: Remove hardcoded Windows paths for production image serving

Problem:
- Images were missing when accessing from mobile/production
- Backend had hardcoded Windows absolute paths (D:/DoAn/...)
- These paths only work on local Windows, not on Linux servers

Changes:
- ImageService.java: Replace all hardcoded paths with @Value uploadPath
  * uploadArticleImage() - use configurable path
  * uploadImage() - use configurable path
  * saveBase64Image() - use configurable path
  * deleteImage() - use configurable path
  * getImage() - use configurable path

- ImageController.java: Add @Value uploadPath and use it
  * Add @Value annotation for uploadPath
  * getProfileImage() - use configurable path
  * getCoverImage() - use configurable path
  * getArticleImage() - use configurable path

- application-prod.yml: Add default APP_BASE_URL
  * Set default value for APP_BASE_URL environment variable

Result:
- Images now work on both Windows (local) and Linux (production)
- Code is portable and can be deployed to any server
- Configuration is flexible via environment variables

Note:
- Render uses ephemeral filesystem - uploaded images will be lost on restart
- For production, consider using cloud storage (S3, Cloudinary, etc.)
- See FIX_IMAGES_MISSING_ON_MOBILE_PRODUCTION.md for details
